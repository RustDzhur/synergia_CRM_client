# Редактор шаблонов договоров

Компонент `components/crm/Finance/RichContractEditor.tsx` — «Word-подобный» редактор для шаблонов договоров
(Настройки → Договори) и текста конкретного документа (Бухгалтерия → Договоры).

- Панель: стиль (обычный/H1–H3), жирный/курсив/подчёркнутый/зачёркнутый, выравнивание, списки, ссылка, картинка, меню «…».
- Под панелью — полоса спецполей: вкладки групп, поиск, фильтр по стране, вид «плашки/список». Поле можно **перетащить мышью**
  в текст или **кликнуть** (вставится в позицию курсора). В тексте поле — синяя плашка `{{ключ}}`.
- Хранение: ограниченный HTML (`lib/finance/contractHtml.ts`, санитайзер на сервере в `cleanBody`). Старые текстовые шаблоны
  с `{{ключ}}` продолжают работать как есть.
- При создании договора поля подставляются автоматически из карточки клиента/фирмы (`lib/finance/contractVars.ts`),
  значения экранируются. PDF рисует `lib/finance/contractRich.ts`.
- Импорт .docx/.txt превращается в HTML (`lib/docxText.ts`).

Каталог полей — см. `docs/CONTRACT_FIELDS.md`.
