# Агенты, которые пишут для сайта (DeepSeek Harness и др.)

Агент, который работает на сервере (например, в DeepSeek Harness), получает доступ к блогу лендинга **одним токеном** и только
на право «читать список статей и класть статьи в блог». К данным фирм, пользователям, почте и настройкам этот токен не
открывает ничего (`lib/agentBlog.ts`, `app/api/agent/blog/route.ts`).

## Включить (один раз, делает владелец)

1. Выдумайте длинный случайный токен на сервере (в чат его не присылайте):
   ```bash
   openssl rand -hex 32
   ```
2. Впишите его в `.env` приложения на сервере (`~/crm-duplicate/deploy/.env`) строкой `AGENT_BLOG_TOKEN=<токен>` и
   пересоздайте контейнер: `cd ~/crm-duplicate && docker compose -f deploy/docker-compose.yml up -d`.
   Пока переменной нет (или она короче 24 знаков), API отвечает 503 «доступ агентов выключен».
3. Дайте агенту токен и адрес: с самого сервера — `https://www.firmspace.de` (или `http://127.0.0.1:3210`, если агент
   не в контейнере). Отозвать доступ — убрать строку и пересоздать контейнер.
4. Необязательно: `AGENT_BLOG_AUTOPUBLISH=1` разрешает агенту публиковать сразу (`publish: true`). По умолчанию статьи
   сохраняются **черновиками**, а публикует владелец командой Айрис: «какие черновики статей есть?», «опубликуй статью …»
   (инструменты `list_blog_posts` и `publish_blog_post`, только для администратора платформы).

## Что отправляет агент

Чтение — какие статьи уже есть (чтобы не повторяться):
```bash
curl -s -H "Authorization: Bearer $AGENT_BLOG_TOKEN" https://www.firmspace.de/api/agent/blog
curl -s -H "Authorization: Bearer $AGENT_BLOG_TOKEN" "https://www.firmspace.de/api/agent/blog?slug=some-slug"
```

Запись — статья на трёх языках (все три обязательны: en, de, ua), текст без HTML:
```bash
curl -s -X POST https://www.firmspace.de/api/agent/blog \
  -H "Authorization: Bearer $AGENT_BLOG_TOKEN" -H "Content-Type: application/json" \
  -d '{
    "slug": "how-to-qualify-leads",
    "title":   { "en": "How to qualify leads", "de": "…", "ua": "…" },
    "excerpt": { "en": "One or two sentences for the blog list", "de": "…", "ua": "…" },
    "body": [
      { "en": "First paragraph", "de": "…", "ua": "…" },
      { "en": "Second paragraph", "de": "…", "ua": "…" }
    ]
  }'
```
Поля: `slug` (латиница, цифры, дефисы; если не задан — строится из английского заголовка), `title` до 160 знаков, `excerpt` до 400,
`body` — до 60 абзацев по 4000 знаков, `image` — только путь вида `/images/blog/имя.jpg` (если не задан — картинка по умолчанию).
Опубликованную статью без `"overwrite": true` перезаписать нельзя (ответ 409). Лимит — 30 записей в час. Ошибки приходят
понятным текстом в поле `message` — агент может сам исправиться.

## Инструкция для агента (вставьте в его задачу)

> Ты автор блога Firmspace AI (платформа для малого бизнеса: CRM, финансы, склад, ИИ-ассистент Айрис). Раз в N дней пиши одну
> статью для лендинга: практичную, без воды, 5–8 абзацев, тема из мира продаж, CRM, учёта, автоматизации. Каждая статья — на
> трёх языках (en, de, ua), текст без HTML и без выдуманных цифр/цен/обещаний про продукт. Перед написанием получи список
> существующих статей (GET) и не повторяй темы. Отправляй статью POST-запросом на `/api/agent/blog` с заголовком
> `Authorization: Bearer <токен>`; она сохранится черновиком — публикует владелец. Токен никуда не выводи и не записывай в файлы.
