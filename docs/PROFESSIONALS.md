# Платформа для бухгалтеров и юристов (практики)

Решение (docs/TZ_MASTER.md §5): платформа — рабочий кабинет специалиста, а не его замена и не посредник. ИИ готовит черновики, подпись и ответственность — человека.

## Что есть (S3)
- **Практика** (`Practice`, `PracticeMember` с ролями partner / senior / junior / assistant) — открывается с обязательным акцептом договора обработки данных и обязательства о тайне (версия и время акцепта хранятся; тексты готовит юрист).
- **Связь с клиентом** (`ClientLink`): приглашение в обе стороны — практика создаёт токен, клиент вводит его; либо клиент вводит код практики, партнёр подтверждает и назначает сотрудников. Принимать и отзывать может только владелец или администратор фирмы клиента.
- **Роли в фирме клиента** `advisor` (бухгалтер) и `counsel` (юрист) — через `Membership.link`. Разделы — только `inventory`, `crm`, `tasks`, `collab` (`PRACTICE_GRANTABLE`); оплата, команда, настройки, автоматизация, почта и маркетинг не выдаются никогда. Роль нельзя назначить через «Команду».
- **Уровни доступа**: `read` — только чтение; `review` — чтение + `/api/review/*` (S4); `edit` — запись в выданных разделах. Реквизиты фирмы (`/api/finance/settings`) специалист не меняет ни на каком уровне.
- **Согласие** (`ConsentRecord`): создаётся при включении связи, отзывается при завершении; срок связи (`expiresAt`) закрывает доступ сам.
- **Немедленный отзыв**: проверка связи идёт на каждом запросе специалиста без кэша (`lib/practice/gate.ts`); завершение связи удаляет членства; уход сотрудника из практики закрывает его доступ ко всем клиентам.
- **Журнал доступа** (`AccessLogEntry`) виден клиенту: каждая запись — строкой, чтения — не чаще раза в 10 минут на раздел.
- Экран: Настройки → «Бухгалтер / юрист» (сторона клиента и сторона практики).

## Чего нет и почему
- Каталога специалистов и поиска исполнителей: юридическая квалификация посредничества не проверена.
- Комиссий с услуг специалистов и подписи отчётов платформой.
- ИИ над данными клиентов практики: режим по умолчанию `none`; включение — отдельное решение (S7).

## Дальше (S4)
