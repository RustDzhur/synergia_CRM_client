# Узбекистан (UZ) — режим рынка, версия 1 (бета)

Статус: **бета для пилотов**. Правила и формы загружены из открытых источников и не проверены специалистом Узбекистана
(`docs/TZ_MASTER.md`, §4). Пока хотя бы одна запись `TaxRule` без `verifiedBy`, в бухгалтерии UZ-фирмы висит плашка «Бета».

## Что есть
- Рынок `UZ` в реестре (`lib/finance/market.ts`): валюта `UZS`, документы на `uz` + `ru`, часовой пояс `Asia/Tashkent`.
- Реквизиты фирмы — одно поле `FinanceSettings.uz` (`lib/validation/uz.ts`): STIR (ИНН), JShShIR (ПИНФЛ, 14 цифр), код плательщика QQS, банк, МФО (5 цифр), расчётный счёт (20 цифр), директор, главный бухгалтер, режим налогообложения, дата постановки плательщиком QQS, оператор ЭСФ.
  Длина ИНН не подтверждена источниками — проверяются только цифры (9–14) и в интерфейсе стоит пометка.
- Налоговые правила — таблица `TaxRule` (`lib/finance/taxRulesData.ts` — начальные записи, `lib/finance/taxRules.ts` — доступ). Правило выбирается **на дату документа**.
- QQS-отчёт (`GET /api/finance/reports?kind=uz-vat`): продажи и входной налог по ставкам, режим фирмы, предупреждения кодами `uzWarn_*`.
- PDF: двуязычные «uz / ru» подписи (`lib/finance/pdfLabelsUz.ts`), реквизиты из `uz`.
- Типовой договор uz/ru (каркас, не юридический образец).

## Что сознательно НЕ входит в версию 1
Отправка ЭСФ/ЭТТН оператору и подпись ЭЦП; онлайн-касса; Payme/Click/Uzum; проводки и план счетов НСБУ; подача отчётности; автозаполнение по ИНН.

## Начальные правила (все `verifiedBy = null`)
| Код | Значение | Действует | Источник |
|---|---|---|---|
| `vat_standard` | 12 % | с 2026-01-01 | EY Uzbekistan Tax Alert (июнь 2026), bizreg.uz |
| `vat_simplified` | 6 %, добровольный, без зачёта входного НДС | 2026-06-01 … 2029-12-31 | EY, Gazeta.uz 29.05.2026 |
| `vat_export` | 0 % | с 2026-01-01 | bizreg.uz (вторичный) |
| `vat_registration_threshold` | 1 млрд сумов → 12 000 БРВ (≈ 5 млрд) | до 2026-05-31 / с 2026-06-01 | EY, Gazeta.uz |
| `profit_tax` | 15 % | с 2026-01-01 | bizreg.uz (вторичный) |
| `turnover_tax` / `turnover_tax_micro` | 4 % / 1 % | с 2026-01-01 | вторичные источники |

Изменение закона — **новая запись** `TaxRule` (с `validFrom`), а не правка кода. Подтверждение специалистом — заполнение `verifiedBy`/`verifiedAt`.
