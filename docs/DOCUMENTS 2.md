# Online Documents: Google Docs и хранилище файлов

## Как это работает

* **Google Docs / Sheets / Slides** создаются через Google Drive API на **Google Drive самого пользователя** (доступ `drive.file`: CRM видит
  только файлы, которые создала сама). Список, папки и метаданные хранятся в CRM, содержимое — у Google.
* **Редактирование идёт в редакторе Google в новой вкладке.** Встроить редактор Google Docs в страницу другого сайта нельзя (Google запрещает
  показ в iframe), поэтому CRM открывает документ на docs.google.com. Google сохраняет изменения сам; кнопка обновления в CRM подтягивает
  новые имена и даты изменения, а документы, удалённые в корзину на Диске, убирает из списка.
* **Папки**: дерево папок в CRM зеркалируется в Drive (корень «Firmspace CRM», внутри — папки CRM). Перенос и переименование отражаются в Drive.
  Папку можно удалить, только если она пуста.
* **Файлы и фото** загружаются в **Firebase Storage** (обычный бакет Google Cloud Storage), путь `users/<пользователь>/<файл>/<имя>`.
  Скачивание идёт через CRM с проверкой владельца; показать прямо в браузере можно только JPEG/PNG/GIF/WebP/PDF, остальное — скачиванием.
  Фото больше 1,5 МБ уменьшаются в браузере до 2048 px. Ограничения: **4 МБ на файл** (предел запроса у функций Vercel), 500 МБ на пользователя,
  исполняемые файлы не принимаются.

## Что нужно настроить (один раз)

### Google Drive
1. Google Cloud Console → тот же проект, что для почты (или новый) → **APIs & Services → Library → Google Drive API → Enable**.
2. На экране согласия OAuth добавьте scope `.../auth/drive.file` (он не «чувствительный», проверка Google обычно не нужна).
3. Ключи `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` — те же, что для почты; **Redirect URI тот же**: `APP_URL/api/mail/oauth/callback`.
4. Пользователь нажимает **Connect Google Drive** в разделе Online Documents и разрешает доступ.

### Firebase Storage
> С 2024–2026 годов Cloud Storage for Firebase **недоступен на бесплатном тарифе Spark**: нужен тариф **Blaze** (привязана карта). Пока вы в пределах
> бесплатной квоты Google Cloud (5 ГБ хранения и 100 ГБ исходящего трафика в месяц), счёт остаётся нулевым.

1. Firebase Console → создайте проект → **Build → Storage → Get started** (для этого потребуется Blaze).
2. **Project settings → Service accounts → Generate new private key** — скачается JSON.
3. В Vercel добавьте переменные:
   * `FIREBASE_SERVICE_ACCOUNT` — содержимое JSON целиком (или его base64);
   * `FIREBASE_STORAGE_BUCKET` — имя бакета со страницы Storage, например `my-project.firebasestorage.app`.
4. Переразверните проект. Пока переменных нет, кнопка загрузки файлов сообщает, что хранилище не подключено.

## Что проверено

На имитации Google Drive API и Cloud Storage: подключение Drive через OAuth, зеркало папок, создание/переименование/перенос, синхронизация имён
и удаления из Google, загрузка и скачивание файлов, подпись токена сервисного аккаунта (RS256), лимиты, чужие файлы недоступны (404),
защита имён файлов; интерфейс — в браузере. **Не проверено с настоящими Google и Firebase** (нужны ваши аккаунты): реальное создание документа,
экран согласия, реальная квота и настройки Blaze.
