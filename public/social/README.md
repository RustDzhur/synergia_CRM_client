# Тестовое видео для публикации

Положите сюда короткий MP4 (например, `test.mp4`) — карточка Настройки → Интеграции →
YouTube/TikTok использует путь `public/social/test.mp4` по умолчанию.

- Тест YouTube загружается как **private** (или unlisted) и расходует 1600 units квоты.
- Тест TikTok уходит в **inbox** (черновик), публично ничего не выходит.
- Без подключённых токенов тест возвращает mock: файл не обязателен.

Большие файлы в git не кладём: тестовый ролик — локальный артефакт, его можно не коммитить.
